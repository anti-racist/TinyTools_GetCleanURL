# Get Clean URL

Removes the tracking parts of a link and copies the clean version.

## What's New in 2.2

- ✨ Removes more trackers, including ones from Google, HubSpot, MailerLite and Reddit.

## Key Features

- Cleans the current page's link and copies it in one click
- Cleans every open tab at once, one link per line
- Shortens Amazon product links

## How to Use

1. Click the Get Clean URL icon. The clean link is copied.
2. To copy every open tab, click **Copy all open tabs**.

## Privacy

Nothing leaves your browser, and the extension has no server.

Full details: [privacy policy](PRIVACY.md).

## Compatibility

Compatible with most Chromium-based browsers, including Google Chrome, Microsoft Edge and Vivaldi.
